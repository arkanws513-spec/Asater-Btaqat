# أساطير البطاقات

لعبة بطاقات عربية تعمل من المتصفح، وتتضمن المبارزات وأوضاع اللعب وبرج الامتياز.

## التشغيل
1. افتح `index.html` في متصفح حديث.
2. تأكد من السماح بملفات JavaScript والتخزين المحلي.
3. تتطلب ميزات الحسابات والمطابقة عبر الإنترنت إعداد مشروع Supabase صالحًا؛ لا تضع مفاتيح الخدمة السرية داخل ملفات الواجهة.

## ملفات رئيسية
- `index.html`: واجهة اللعبة.
- `duel.js` و`duel.css`: نظام المبارزة.
- `modes.js` و`modes.css`: أوضاع اللعب والتقدم.

## الفحوص
فحص الصياغة عبر `node --check duel.js` و`node --check modes.js`. هذا الفحص لا يغني عن اختبار اللعب داخل المتصفح أو اختبار إعداد Supabase.
